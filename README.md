# ⚡ Zed XiaoAI External Agent

> Кастомный **External Agent (ACP)** для редактора **Zed** с поддержкой роутера моделей **XiaoAI**.  
> **Автор проекта:** [@thriveera](https://github.com/thriveera)

---

## 🌟 Преимущества

- **Красивый EXE-установщик**: для Windows доступен готовый графический установщик `XiaoAI-Zed-Installer.exe` — всё настраивается через визуальный интерфейс в пару кликов.
- **Подписи с ценами прямо в интерфейсе чата Zed**: цены за 1M токенов не нужно искать на сторонних сайтах — они отображаются непосредственно в самом интерфейсе Zed на кнопке и в выпадающем списке выбора модели (например, `GPT 6.1 Sol — $0.08 / 1M`, `ChatGPT 4o mini — Free`).
- **Гибкая синхронизация моделей, контекста и цен**:
  - Настройка частоты обновления каталога: **при каждом запуске агента (автоматически)**, **каждые 6 часов**, **каждые 24 часа** или **вручную**.
  - При синхронизации агент автоматически опрашивает роутер XiaoAI и обновляет актуальный список моделей, их контекстные окна и цены.
- **Безопасное шифрование ключей**: API-ключи пользователей **не сохраняются в открытом виде**. Они шифруются на уровне операционной системы через **Keyring** (Windows Credential Locker, macOS Keychain, Linux SecretService).
- **Стриминг и рассуждения (Reasoning / Thinking)**: поддержка раздельного вывода цепочки рассуждений (`AgentThoughtChunk`) и текста ответа.
- **Удобные слэш-команды в чате**:
  - `/sync` — принудительно обновить каталог моделей и цен с роутера прямо во время диалога.
  - `/status` — проверить статус ключа, баланс счёта и текущий режим синхронизации.
  - `/models` — показать подробный список доступных моделей с их прайсом и контекстом.
  - `/setkey <ключ>` — обновить API-ключ в зашифрованном хранилище прямо из чата.

## 🚀 Установка

### Вариант 1: Через графический EXE-установщик (Windows, рекомендуется)
1. Перейдите во вкладку [Releases](https://github.com/thriveera/zed-xiaoai-agent/releases) и скачайте **`XiaoAI-Zed-Installer.exe`**.
2. Запустите программу.
3. Введите ваш API-ключ XiaoAI (можно нажать «Проверить», чтобы увидеть баланс).
4. Выберите желаемую частоту синхронизации моделей (по умолчанию — автоматически при каждом запуске).
5. Нажмите **«Установить / Обновить в Zed»**.
6. Запустите **Zed** $\to$ нажмите **`Ctrl + ?`** $\to$ выберите **`XiaoAI Agent`**!

---

### Вариант 2: Через архив скриптов (Windows / macOS / Linux)
1. Скачайте архив **`zed-xiaoai-agent-v1.1.1.zip`** со страницы [Releases](https://github.com/thriveera/zed-xiaoai-agent/releases).
2. Распакуйте и запустите:
   - **Windows**: `install.bat`
   - **macOS / Linux**: `./install.sh`
3. Следуйте подсказкам установщика.

---

## 🗑️ Удаление

- **В графическом установщике**: нажмите красную кнопку **«🗑️ Удалить из Zed»**. Агент будет отключен, а API-ключ автоматически стёрт из системного хранилища.
- **Через консоль**: выполните команду `python install.py --uninstall`.

---

## 🔒 Безопасность

- Ключ **не записывается в открытом виде** в `settings.json`.
- Агент извлекает ключ из системного защищённого хранилища через `keyring`.
