# ⚡ Zed XiaoAI External Agent

> Кастомный **External Agent (ACP)** для редактора **Zed** с поддержкой роутера моделей **XiaoAI**.  
> **Автор проекта:** [@thriveera](https://github.com/thriveera)

---

## 🌟 Преимущества

- **Установка в 1 клик**: готовый скрипт установки `install.bat` / `install.sh` сам настраивает всё окружение и прописывает агента в Zed.
- **Безопасное хранение ключей**: API-ключи пользователей **не хранятся в открытом тексте**. Они шифруются на уровне операционной системы через **Keyring** (Windows Credential Locker, macOS Keychain, Linux SecretService).
- **Динамический каталог моделей**: при старте и по команде `/sync` агент обращается к роутеру XiaoAI и автоматически загружает все новые модели.
- **Интеграция в интерфейс Zed**: выбор моделей доступен прямо в выпадающем списке панели агента Zed (`Ctrl + ?` / `Cmd + ?`).
- **Стриминг и рассуждения (Reasoning / Thinking)**: поддержка раздельного вывода цепочки рассуждений (`AgentThoughtChunk`) и текста ответа.
- **Удобные слэш-команды в чате**:
  - `/sync` — обновить каталог моделей с роутера прямо во время сессии.
  - `/status` — проверить статус ключа и текущий баланс счёта.
  - `/models` — показать список всех моделей с лимитами токенов.
  - `/setkey <ключ>` — обновить API-ключ в зашифрованном хранилище прямо из чата.

## 🚀 Простая установка (для пользователей релиза)

1. Скачайте архив релиза **`zed-xiaoai-agent-v1.0.1.zip`** со страницы [Releases](https://github.com/thriveera/zed-xiaoai-agent/releases) и распакуйте его в удобную папку.
2. Запустите автоматический установщик:
   - **Windows**: просто дважды кликните по файлу **`install.bat`** (или выполните `python install.py`).
   - **macOS / Linux**: запустите в терминале **`./install.sh`** (или `python3 install.py`).
3. Введите ваш API-ключ XiaoAI при запросе.
   - Установщик проверит ключ, зашифрует его в хранилище системы и сам подключит агента в файл конфигурации Zed (`settings.json`).
4. Откройте **Zed** $\to$ нажмите **`Ctrl + ?`** (или `Cmd + ?`) $\to$ переключитесь на **`XiaoAI Agent`**!

---

## 🔒 Безопасность

- Ключ **не записывается в открытом виде** в `settings.json`.
- Агент извлекает ключ из системного защищённого хранилища через `keyring`.
