# ⚡ Zed XiaoAI External Agent

> Кастомный **External Agent (ACP)** для редактора **Zed** с поддержкой роутера моделей **XiaoAI**.  
> **Автор проекта:** [@thriveera](https://github.com/thriveera)

---

## 🌟 Преимущества

- **Красивый EXE-установщик**: для Windows доступен готовый графический установщик `XiaoAI-Zed-Installer.exe` — не нужно вводить команды в терминале, всё настраивается через визуальный интерфейс в пару кликов.
- **Безопасное шифрование ключей**: API-ключи пользователей **не сохраняются в открытом виде**. Они шифруются на уровне операционной системы через **Keyring** (Windows Credential Locker, macOS Keychain, Linux SecretService).
- **Динамический каталог моделей**: при старте и по команде `/sync` агент обращается к роутеру XiaoAI и автоматически загружает все новые модели.
- **Интеграция в интерфейс Zed**: выбор моделей доступен прямо в выпадающем списке панели агента Zed (`Ctrl + ?` / `Cmd + ?`).
- **Стриминг и рассуждения (Reasoning / Thinking)**: поддержка раздельного вывода цепочки рассуждений (`AgentThoughtChunk`) и текста ответа.
- **Удобные слэш-команды в чате**:
  - `/sync` — обновить каталог моделей с роутера прямо во время сессии.
  - `/status` — проверить статус ключа и текущий баланс счёта.
  - `/models` — показать список всех моделей с лимитами токенов.
  - `/setkey <ключ>` — обновить API-ключ в зашифрованном хранилище прямо из чата.

## 🚀 Установка

### Вариант 1: Через графический EXE-установщик (Windows, рекомендуется)
1. Перейдите во вкладку [Releases](https://github.com/thriveera/zed-xiaoai-agent/releases) и скачайте **`XiaoAI-Zed-Installer.exe`**.
2. Запустите программу.
3. Введите ваш API-ключ XiaoAI (можно нажать «Проверить», чтобы увидеть статус и баланс).
4. Нажмите **«Установить XiaoAI Agent в Zed»**.
5. Запустите **Zed** $\to$ нажмите **`Ctrl + ?`** $\to$ переключитесь на **`XiaoAI Agent`**!

---

### Вариант 2: Через архив скриптов (Windows / macOS / Linux)
1. Скачайте архив **`zed-xiaoai-agent-v1.0.2.zip`** со страницы [Releases](https://github.com/thriveera/zed-xiaoai-agent/releases).
2. Распакуйте и запустите:
   - **Windows**: `install.bat`
   - **macOS / Linux**: `./install.sh`
3. Следуйте подсказкам в окне.

---

## 🔒 Безопасность

- Ключ **не записывается в открытом виде** в `settings.json`.
- Агент извлекает ключ из системного защищённого хранилища через `keyring`.
